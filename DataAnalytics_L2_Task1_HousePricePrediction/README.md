# 🏠 House Price Prediction — Linear Regression

## 📌 Project Overview

This project was completed as part of the **Oasis Infobyte Data Analytics Internship Program**.

The objective is to build a **Linear Regression model** to predict house prices based on different property features.

## 🎯 Objectives

- Inspect and clean the housing dataset
- Perform Exploratory Data Analysis
- Analyse important features affecting house prices
- Encode categorical variables
- Perform correlation analysis
- Split data into training and testing sets
- Build a Linear Regression model
- Evaluate the model using MSE, RMSE and R²
- Analyse actual vs predicted prices
- Perform residual and coefficient analysis

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset

The housing dataset contains property information such as:

- Area
- Bedrooms
- Bathrooms
- Stories
- Parking
- Main Road
- Guest Room
- Basement
- Air Conditioning
- Preferred Area
- Furnishing Status
- Price

The **Price** column is used as the target variable.

## 🔍 Analysis Performed

- Data inspection and preprocessing
- Exploratory Data Analysis
- Categorical feature encoding
- Correlation analysis
- 80/20 train-test split
- Linear Regression modelling
- MSE, RMSE and R² evaluation
- Actual vs Predicted analysis
- Residual analysis
- Feature coefficient analysis

## 📈 Key Visualisations

- House Price Distribution
- Area vs House Price
- Correlation Heatmap
- Actual vs Predicted Prices
- Residual Plot
- Feature Coefficient Analysis

## 📤 Output

The project includes the completed Jupyter Notebook, model performance metrics, predictions, and generated visualisations.
