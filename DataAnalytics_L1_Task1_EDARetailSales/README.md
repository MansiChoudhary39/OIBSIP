# 📊 Exploratory Data Analysis — Retail Sales Dataset

## 📌 Project Overview

This project was completed as part of the **Oasis Infobyte Data Analytics Internship Program**.

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on a retail sales dataset to identify sales trends, customer behaviour, product performance, and actionable business insights.

## 🎯 Objectives

- Inspect and understand the dataset
- Check missing values and duplicate records
- Calculate descriptive statistics
- Analyse monthly and quarterly sales trends
- Analyse customer age groups and gender distribution
- Analyse revenue by product category
- Analyse quantity sold by product category
- Perform correlation analysis
- Create meaningful data visualisations
- Generate actionable business recommendations

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Dataset

The dataset contains retail transaction information including:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

## 🔍 Analysis Performed

### 1. Dataset Inspection

- Checked dataset shape
- Inspected column names
- Checked data types
- Checked missing values
- Checked duplicate records

### 2. Data Preparation

- Converted the Date column to datetime format
- Created Month and Quarter features
- Created customer Age Groups

### 3. Descriptive Statistics

Calculated the following statistics for numerical variables:

- Mean
- Median
- Mode
- Standard Deviation

### 4. Sales Trend Analysis

Analysed:

- Monthly sales trends
- Quarterly sales trends

Line charts were used to visualise changes in sales over time.

### 5. Customer Demographics

Analysed:

- Customer age group distribution
- Gender distribution

### 6. Product Analysis

Analysed:

- Revenue by product category
- Quantity sold by product category
- Top-selling products where product-level data was available

### 7. Correlation Analysis

A correlation heatmap was created to understand relationships between numerical variables such as:

- Age
- Quantity
- Price per Unit
- Total Amount

### 8. Additional Analysis

Customer spending behaviour was analysed across different age groups and product categories to identify additional business insights.

1. Focus marketing campaigns on high-performing customer groups based on demographic and spending patterns.

2. Prioritise inventory planning for product categories generating higher revenue and demand.

3. Use monthly and quarterly sales trends to improve inventory management and promotional planning.
