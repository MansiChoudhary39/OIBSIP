# 📱 Google Play Store Analysis

## 📌 Project Overview

This project was completed as part of the **Oasis Infobyte Data Analytics Internship Program**.

The objective is to analyse the Google Play Store ecosystem by exploring app categories, ratings, installs, pricing, revenue potential, and user sentiment.

## 🎯 Objectives

- Clean and preprocess Play Store data
- Analyse app categories and ratings
- Study installs and app size
- Compare free and paid applications
- Estimate revenue by category
- Perform sentiment analysis on user reviews
- Create meaningful visualisations
- Generate data-driven insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- TextBlob
- Plotly
- Jupyter Notebook

## 📊 Dataset

The project uses two datasets:

- Google Play Store Apps Dataset
- Google Play Store User Reviews Dataset

The datasets contain information about app categories, ratings, reviews, installs, size, price, and user feedback.

## 🔍 Analysis Performed

- Data cleaning and preprocessing
- App category analysis
- Rating analysis
- Size and installs analysis
- Free vs paid app analysis
- Price and revenue analysis
- User sentiment analysis
- Sentiment analysis by category
- Interactive visualisation using Plotly

## 📈 Key Visualisations

- App Distribution by Category
- Rating Distribution
- Average Rating by Category
- App Size vs Installs
- Free vs Paid Apps
- Paid App Price Distribution
- Estimated Revenue by Category
- Top Installed Apps
- Sentiment Distribution
- Sentiment by Category

## 📤 Output

The project includes cleaned datasets, the completed Jupyter Notebook, generated charts, and analysis results.
