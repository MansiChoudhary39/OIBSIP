# 🧹 Data Cleaning and Preprocessing — Titanic Dataset

## 📌 Project Overview

This project was completed as part of the **Oasis Infobyte Data Analytics Internship Program**.

The objective is to clean and preprocess the Titanic dataset and transform it into a reliable, analysis-ready dataset.

## 🎯 Objectives

- Inspect the dataset
- Identify missing values and duplicates
- Handle missing data
- Standardise inconsistent data
- Correct data types
- Detect outliers using the IQR method
- Compare data quality before and after cleaning
- Export the cleaned dataset

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Dataset

The Titanic dataset contains passenger information such as:

- Passenger ID
- Passenger Class
- Name
- Sex
- Age
- SibSp
- Parch
- Ticket
- Fare
- Cabin
- Embarked
- Survival

## 🔍 Data Cleaning Performed

- Dataset quality assessment
- Missing value analysis and handling
- Duplicate detection and removal
- Categorical data standardisation
- Data type correction
- IQR-based outlier detection
- Before vs After data quality comparison

## 📤 Output

The cleaned and analysis-ready dataset is exported as:

`cleaned_titanic.csv`
